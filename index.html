Panduan Koneksi Google Sheets & Kamera Bebas Blokir

Sinkronisasi real-time antar perangkat via Google Apps Script

  1. Buka Google Sheets → Ekstensi → Apps Script, lalu tempel file Code.gs dan index.html.
  2. Klik Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone).
  3. Salin URL Web App ke kolom URL di aplikasi ini lalu klik Simpan URL.
  4. Tips Kamera Bebas Blokir: Untuk kamera live yang langsung menyala di HP & Laptop tanpa blokir iframe Apps Script, upload file HTML ini ke hosting HTTPS gratis (misal Netlify Drop / GitHub Pages) lalu tempel URL Web App Apps Script di kolom URL.
